# GieN Music Store

GieN Music Store adalah website landing page katalog produk musik yang dibuat sebagai tugas mata kuliah Pemrograman Web.

Website ini dirancang untuk menampilkan berbagai produk musik dan audio seperti gitar, bass, microphone, headphone, biola, amplifier, keyboard, dan drum. Website dibuat dengan pendekatan responsive design sehingga dapat menyesuaikan tampilan pada perangkat mobile, tablet, maupun desktop.

## Tujuan

Website ini dibuat untuk menerapkan konsep dasar pengembangan web menggunakan HTML5 dan CSS3, khususnya:

- HTML5 Semantik
- Accessibility
- Responsive Web Design
- CSS Flexbox
- CSS Grid
- CSS Custom Properties
- Media Query
- Struktur project yang terorganisir

## Teknologi yang Digunakan

- HTML5
- CSS3
- Git
- GitHub

Website ini dibuat tanpa menggunakan framework CSS seperti Bootstrap, Tailwind CSS, atau library frontend lainnya.

## Fitur Website

### 1. Hero Section

Menampilkan identitas GieN Music Store, slogan, deskripsi singkat, serta tombol untuk melihat produk dan informasi lebih lanjut.

### 2. Kategori Produk

Menampilkan beberapa kategori produk musik yang tersedia, yaitu:

- Gitar
- Bass
- Biola
- Microphone
- Amplifier
- Headphone
- Keyboard
- Drum

### 3. Produk Unggulan

Menampilkan beberapa produk unggulan beserta:

- Nama produk
- Deskripsi
- Harga
- Kategori
- Tombol untuk melihat produk

Produk yang ditampilkan antara lain:

- GieN Electric Guitar X1
- GieN Bass B4
- GieN Studio Mic M1
- GieN Studio H7

### 4. Tentang GieN Music Store

Berisi informasi singkat mengenai GieN Music Store serta beberapa keunggulan toko.

### 5. Testimoni

Menampilkan beberapa testimoni pelanggan sebagai informasi pendukung dan meningkatkan kepercayaan terhadap toko.

### 6. Call to Action

Menyediakan bagian ajakan kepada pengguna untuk melihat produk dan menghubungi GieN Music Store.

### 7. Responsive Design

Website menggunakan pendekatan mobile-first dan memiliki breakpoint untuk:

- Mobile: tampilan default
- Tablet: `min-width: 768px`
- Desktop: `min-width: 1024px`

Dengan demikian, tampilan website dapat menyesuaikan berbagai ukuran layar.
